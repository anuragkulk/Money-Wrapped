# FINCOSMOS — Money Wrapped

**Understand your spending. Discover your habits. Make your money count.**

FINCOSMOS — Money Wrapped is a student-focused personal finance insights tool that helps users understand where their money goes. By uploading a bank transaction statement, users can turn raw transaction data into a clear, visual, and engaging monthly spending report.

Inspired by the engaging, personalized experience of Spotify Wrapped, FINCOSMOS presents financial information in a simple and interactive format.

## The Problem

Students frequently make small daily purchases on food, transport, shopping, subscriptions, and other expenses without realizing how these transactions add up over time.
Manually tracking every expense can be tedious, and traditional bank statements are not always easy to interpret.

## Our Solution

FINCOSMOS simplifies spending analysis by processing uploaded transaction statements, categorizing expenses, calculating spending patterns, and presenting the results through an interactive dashboard and a personalized Money Wrapped report.

## Key Features

- **Bank Statement Upload:** Import supported transaction files to begin analyzing spending.
- **Automatic Categorization:** Group transactions into categories such as Food & Dining, Transport, Shopping, Education, Subscriptions, and more.
- **Spending Dashboard:** View total expenses, category-wise breakdowns, and other useful spending metrics.
- **Money Wrapped Report:** Explore personalized insights about spending habits, top categories, frequent merchants, and spending patterns.
- **Transaction Review:** Review transactions and correct categories when automatic categorization is inaccurate.
- **Financial Awareness:** Discover spending patterns and identify opportunities to manage money more effectively.

*Features depend on the current implementation. Supported file formats and available report options should be confirmed in the deployed version.*

## How It Works

1. **Upload:** The user uploads a supported bank transaction statement.
2. **Parse:** The application reads transaction dates, descriptions, amounts, and other available fields.
3. **Categorize:** Transactions are assigned categories using categorization rules.
4. **Review:** The user checks uncertain or incorrectly categorized transactions and makes corrections where supported.
5. **Analyze:** The application calculates spending totals, category breakdowns, and other insights from the transaction data.
6. **Discover:** The user explores the dashboard and personalized Money Wrapped report.

## Privacy and Responsible Use

Financial transaction data is sensitive. FINCOSMOS is intended to help users understand their spending without requiring them to share online banking credentials.
FINCOSMOS provides spending insights for educational and informational purposes. It does not provide professional financial advice.

## Built For

FINCOSMOS is being developed as a student-focused financial awareness project associated with FinCosmos Club.
Our goal is to make personal finance easier to understand through useful insights, approachable design, and engaging data visualization.

## Future Scope
